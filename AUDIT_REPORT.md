## Confirmed/refuted verification targets

### 1. `finalresults.csv` population — **CONFIRMED: populated legacy backup; REFUTED: claim that every such file is empty**

The docs are stale and conflate the missing active output with the populated backup.

### 2. Flat volume bug — **CONFIRMED: still active in newest EA output**
The EA validator documents full-cell relaxation at `ea_step4_validate.py:8-11`, but `staged_relax()` calls `relax_cell=False` at `:113-117`, then explicitly skips Step 2 and returns `pos_relaxed` at `:126-131`. The EA validated result has one unique `chgnet_volume_per_atom` value, 9.426187896551726 Å³/atom, across 20 rows (`earth_abundant/data/results/earth_abundant_candidates_validated.csv:1-21`; mirrored output under `FINAL_Results/Earth_Abundant_Pipeline/earth_abundant_candidates_validated.csv`). This directly refutes README.md:43 and RESULTS.md:56.

### 3. Cross-validation columns — **CONFIRMED: downstream result outputs do not contain CV metrics**
Both trainers run 5-fold R² CV (`02_pipeline/step2_model_training/bayesian_validation.py:62-88`; `earth_abundant/scripts/ea_step2_model_training.py:50-76`) but only print scores and then save a refit model (`...:90-94`; EA `...:78-84`). Output schemas such as `earth_abundant/data/results/ea_gpr_predictions.csv:1` and `FINAL_Results/High_Performance_Pipeline/MASTER_RESULTS.csv:1` contain no `cv_r2_mean`, `cv_r2_std`, fold, or equivalent columns. Thus the “cross-validated” headline is not backed by row-level persisted evidence; it is not a literal blank-column bug, but a missing-column/reporting bug.

### 4. Stability calculations — **CONFIRMED: nonphysical/sentinel stability values are present**
The active EA thermal proxy reports −7.27545 to −9.21063 eV/atom (`earth_abundant/data/results/ea_thermal_stability.csv:2-6`) and labels all five rows `STABLE`; this is not a convex-hull energy and is far outside a credible relative phase-stability scale for this use. The source computes raw candidate-minus-baseline CHGNet energies at `ea_step4_validate.py:207-225` without an energy normalization/scale check. Separately, the thermodynamic output contains `inf` for every populated row (`FINAL_Results/High_Performance_Pipeline/thermodynamic_stability.csv:2-35`), caused by the broad failure sentinel at `thermodynamic_stability.py:54-56,113-115`. Materials Project defines energy above hull in eV/atom and notes values above 200 meV/atom are already very large [1]; `inf` is an error sentinel, not a measured stability value.
