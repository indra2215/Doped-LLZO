## 📁 02_pipeline/ — All Active Scripts

### `step1_feature_extraction/`
| File | Purpose |
|------|---------|
| `fast_surrogate_extraction.py` | **Step 1A**: Reads the experimental dataset and extracts 7 compositional features (Li fraction, electronegativity, mass, radius, etc.) for every formula. Outputs `bayesian_features.csv`. |
| `feature_engineering.py` | **Step 1B**: Shared library of feature extraction functions used by other scripts. Not run directly. |

### `step2_model_training/`
| File | Purpose |
|------|---------|
| `bayesian_validation.py` | **Step 2**: Trains a Gaussian Process Regressor (GPR) + Random Forest on the experimental dataset. The GPR learns to predict ionic conductivity from composition. Saves `trained_gpr_model.pkl`. |
| `trained_gpr_model.pkl` | ✅ **Pre-trained model** — already saved, no need to retrain unless data changes. |

### `step3_screening/`
| File | Purpose |
|------|---------|
| `generate_candidates.py` | **Step 3A**: Generates 14,000+ virtual LLZO candidates using charge-balanced combinatorial chemistry. Outputs `bayesian_virtual_candidates.csv`. |
| `compositional_screening.py` | **Step 3B**: Trains a fast Random Forest screener and ranks all 14,000 candidates. Picks top 50. |
| `evaluate_candidates_chgnet.py` | **Step 3C**: Takes top 50 and does actual CHGNet neural network relaxation. Saves relaxed CIF structures + energy data. The most expensive local step — processes ~35/50 before hitting memory limits. |

### `step4_stability/`
| File | Purpose |
|------|---------|
| `thermodynamic_stability.py` | **Step 4A**: Checks energy above convex hull via Materials Project API. Completed ✅ |
| `dynamical_stability.py` | **Step 4B**: Phonon calculation using Phonopy + CHGNet. Checks for imaginary frequencies. **Needs HPC.** |
| `mechanical_stability.py` | **Step 4C**: Elastic tensor calculation via finite-difference CHGNet stresses. **Needs HPC.** |

### `step5_md_validation/`
| File | Purpose |
|------|---------|
| `backtrack_validation_corrected.py` | **Step 5 (FINAL)**: Runs NVT Langevin Molecular Dynamics at 600K, 800K, 1000K. Fits Arrhenius curve. Extrapolates σ_RT using Nernst-Einstein. **Needs HPC.** |

```

Step 3A: generate_candidates.py        → bayesian_virtual_candidates.csv
Step 3B: compositional_screening.py    → top_50_screened_candidates.csv
Step 3C: evaluate_candidates_chgnet.py → evaluated_top_candidates.csv + *.cif files
Step 4A: thermodynamic_stability.py    → thermodynamic_stability.csv ✅
Step 4B: dynamical_stability.py        → dynamical_stability.csv [HPC]
Step 4C: mechanical_stability.py       → mechanical_stability.csv [HPC]
Step 5:  backtrack_validation.py       → finalresults.csv [HPC]
→ MASTER_RESULTS.csv (consolidated output)
```
